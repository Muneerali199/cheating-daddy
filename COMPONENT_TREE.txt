/**
 * Data Flow
 * 
 * User Actions → Event Handlers → State Updates → Re-render
 * 
 * Example: Send Message
 * 1. User types in MessageInput
 * 2. Clicks Send or presses Enter
 * 3. onSendMessage(content) called
 * 4. App.handleSendMessage updates messages state
 * 5. New message added to array
 * 6. Mock AI response added after 1s timeout
 * 7. ChatWindow receives updated messages
 * 8. Auto-scrolls to bottom
 * 9. UI reflects new state
 * 
 * Example: Select Profile
 * 1. User clicks profile in ProfilePanel
 * 2. onSelectProfile(profile) called
 * 3. App.handleSelectProfile updates selectedProfile
 * 4. System message added to chat
 * 5. SessionPanel header updates with new profile
 * 6. Visual feedback on selected card
 */

/**
 * Component Responsibilities
 * 
 * Presentational (UI Only):
 * - StatusPill: Display connection status
 * - QuickActionCard: Render action card with hover
 * - ChatMessage: Display message bubble
 * 
 * Container (Logic + UI):
 * - App: Global state management
 * - Dashboard: Layout orchestration
 * - SessionPanel: Session info + chat coordination
 * - ChatWindow: Message list + auto-scroll
 * - MessageInput: Input handling + validation
 * - ProfilePanel: Profile list + selection
 * 
 * Layout (Structure):
 * - AppShell: Overall app structure
 * - Sidebar: Navigation layout
 * - TopBar: Header layout
 * - QuickActions: Grid layout
 */

/**

 * --transition-fast, --transition-smooth
 */
